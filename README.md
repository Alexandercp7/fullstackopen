# Full Stack Open

Personal solutions for the [Full Stack Open](https://fullstackopen.com/es/) course (University of Helsinki).

## Contents

- `part0/` — Fundamentals of Web apps
- `part1/` — Introduction to React (`courseinfo`, `unicafe`, `anecdotes`)
- `part2/` — Communicating with server (`courseinfo`, `phonebook`, `countries`)
- `part3/` — Programming a server with NodeJS and Express (`phonebook-backend`)
- `part4/` — Testing Express servers, user administration (`bloglist`)
- `part5/` — Testing React apps (`bloglist-frontend`, `playwright`)
- `part6/` — Advanced state management (`unicafe`, `anecdotes`, `query-anecdotes`)
- `part7/` — React router, custom hooks, styling & webpack (`routed-anecdotes`, `country-hook`, `ultimate-hooks`, `bloglist`)
- `part8/` — GraphQL (`library-backend`, `library-frontend`)
- `part9/` — TypeScript (`healthapp`, `course`, `flightdiaries`, `patientor`)
- `part10/` — React Native (`rate-repository-app`)
